Настройки API

Укажи ключи источников, которые нужно подключить. Если оставить поле пустым, этот источник будет отключён; оба поля можно оставить пустыми и пользоваться ручным вводом.

Ключи сохраняются локально в вашем браузере (LocalStorage).
Состояние источников
Проверь подключение, чтобы узнать, отвечают ли TMDB и Кинопоиск в этом браузере.
CINEVA — независимый проект о кино. Данные карточек, рейтинги и изображения загружаются через API Кинопоиска и TMDB. CINEVA не связан с Кинопоиском или TMDB. Для публичного запуска перенеси ключ API на сервер.
